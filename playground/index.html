Свой терм
  • λ можно набирать как \: \x. x — то же, что λx. x, то есть x => x.
  • Применение — пробел: f a b значит (f a) b, как f(a)(b) в JS.
  • Тело λ тянется вправо до конца: λx. f x — это λx. (f x).
  • Имена из словаря (TRUE, TWO, Y…) — сокращения. Они раскрываются, только когда их вызывают.
  • Подсвеченный кусок — редекс: вызов, который будет выполнен следующим шагом.
